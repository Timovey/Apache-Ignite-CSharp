# Apache Ignite C#

Эксперимент с распределёнными вычислениями на **Apache Ignite.NET**: несколько узлов объединяются в кластер, а
задача делится на части, которые выполняются на разных узлах.

**Стек:** C# · .NET 6 · Apache Ignite 2.14 (Compute Grid)

## Что внутри

- `ArrayTask` — транспонирует матрицу и раздаёт её столбцы задачам `ArrayComputeJob` на узлах кластера по кругу
  (map), затем собирает результаты (reduce).
- `CharCountTask` / `CharCountComputeJob` — подсчёт символов, распределённый по узлам.
- `Program.cs` — запускает узел и выполняет задачу с замером времени (`Stopwatch`).

Узлы находят друг друга через статический список адресов `127.0.0.1:48500..48520` (`TcpDiscoverySpi`).

## Запуск

Нужен .NET 6 SDK и Java (JRE 8+): Ignite.NET работает поверх JVM.

```bash
cd ComputeNode.Main
dotnet run   # первый узел
dotnet run   # в другом терминале — второй узел, он присоединится к кластеру
```
